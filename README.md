# Jin Hao Portfolio

A first-version professional portfolio for Jin Hao, positioned around digital marketing, performance, AI and GEO. All career details and performance results in the site are drawn from `Jin Hao CV Marketing 2026.docx`.

## Run locally on a Mac

1. Install the current LTS version of Node.js from [nodejs.org](https://nodejs.org/).
2. In Terminal, open this project folder:

   ```bash
   cd "/Users/jin/Documents/Codex/2026-09-14/referenced-chatgpt-conversation-this-is-an"
   ```

3. Install the project packages and run the development site:

   ```bash
   npm install
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in a browser.

## Production check

Before publishing, run:

```bash
npm run build
```

## Publish later

Push this folder to a GitHub repository, then import that repository in Vercel. Vercel will recognise this as a Next.js project and build it automatically.
